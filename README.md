# Fibonacci Sequence in Java

This project is a simple Java program that generates the Fibonacci sequence up to a user-specified limit.

## Features

- Generates Fibonacci numbers
- Accepts user input using Scanner
- Displays the sequence in the console
- Uses loops and methods in Java

## Technologies Used

- Java
- IntelliJ IDEA
- Git & GitHub

## Java Code Overview

The program:

- Takes an upper limit from the user
- Generates Fibonacci numbers starting from 0 and 1
- Prints all Fibonacci numbers up to the entered limit

## Fibonacci Sequence Example

```text
0 1 1 2 3 5 8 13 21 ...
```

Each number is the sum of the previous two numbers.

## Sample Output

```text
Enter the upper limit: 20

Fibonacci Sequence:
0 1 1 2 3 5 8 13
```

## How to Run

1. Open the project in IntelliJ IDEA
2. Open `FibonacciSequence.java`
3. Click the Run button
4. Enter the upper limit in the console
